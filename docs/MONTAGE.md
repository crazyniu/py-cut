## 1. 需求原文与解读

用户给的三步流程：

| 步骤 | 素材 | 要求 |
|---|---|---|
| **A** | `/Volumes/Lexar/DevStorage/剪辑/爆款素材/快手/1.mp4` | 提取视频话术，作为**时长与节奏基准** |
| **B** | `/Volumes/Lexar/DevStorage/剪辑/片段` | 随机取片段混剪，**片段不重复**、去重、**静音**；成片时长 = 步骤A |

三条硬约束（来自原文）：
1. **时长对齐**：最终成片时长 = 步骤A 的**声音时长**；
2. **片段不重复**：B/C 两步都不能重复使用同一素材；
3. **静音**：B 步与 C 步产出都无音轨。

## 3. 实现方案

### 步骤A：话术基准（`core/montage_source.py`）

用 ffmpeg `silencedetect` 提取语音区间：

```
ffmpeg -i 1.mp4 -af silencedetect=noise=-32d:d=0.35 -f null -
```

- 结果在 **stderr**，需正则解析 `silence_start:` / `silence_end:`；
- **语音段 = 静音区间的补集**（尾部静音缺 `silence_end` 时要补到结尾，否则漏最后一段）；
- 过滤 <0.8s 的碎段、截断 >8s 的长段、合并间隔 <0.05s 的相邻段；
- 再由语音段规划出**时间槽**（每个槽 = 成片里该段应有的长度），
  以语音为节奏骨架，让成片节奏与原话术一致——这是混剪的核心价值。

> **为什么不接 ASR**：混剪只需要「时长 + 节奏」，不需要文字内容。
> 引入 ASR 要额外装模型（whisper 等），违反 `AGENTS.md` 里
> 「保持标准库 + cv2 + numpy，不引入未装依赖」的约定。如将来要做
> 「按话术语义选片段」，再单独评估。

### 步骤B：随机混剪（`core/montage_clips.py`）

1. 并发探测素材（ffprobe 串行 509 个要几分钟，用线程池），按竖屏 + 时长过滤；
2. 按槽依次随机分配素材，同一素材**不重复使用**；素材不足以填满时允许复用
   但要标 `reused` 并给出 `shortfall`；
3. 拼接：**素材分辨率不一致**（720x1280 / 544x960），且画布是 720x1276，
   用 `scale + pad` 适配（**保持比例，严禁拉伸变形**，不足处补黑）；
4. `-an` 静音 + libx264 + `-fps_mode cfr` + 原子替换。

### 步骤C：画中画叠加（`core/montage_pip.py`）

- 每个画中画是**独立输入**（`-ss <offset> -t <duration>` 在输入侧截取，互不干扰）；
- 一条 filter_complex 里串多个 `overlay`，每个用 `enable='between(t,...)'`
  精确控制出现区间 → 同一时刻右上角只有一个画中画；
- 宽 = 基准宽 × `MONTAGE_PIP_SCALE`(0.26)，**保持宽高比**，右上角留margin；
- 复用 `core/dedup.py` 里已验证的 overlay 写法与「避免二次重采样」的经验。

## 4. 命令

```bash
./run.sh montage                      # 三步全跑
./run.sh montage --step a             # 只提取基准（看语音节奏）
./run.sh montage --step b             # 只到片段混剪
./run.sh montage --no-pip             # 不叠画中画
./run.sh montage --probe              # 只统计素材规模（竖屏/横屏/时长分布）
./run.sh montage --seed 2026          # 固定选片结果可复现
./run.sh montage --allow-landscape    # 放开横屏（默认排除）
```

TUI 里montage 的任务设置页只有三项：**执行到哪一步 / 跳过画中画 / 只探测素材**，
其余（素材路径、CRF、各阈值）都在高级参数页。
